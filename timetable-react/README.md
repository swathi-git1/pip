# Smart Timetable Generator (React)

## Run
    npm install
    npm run dev

Open the URL shown in the terminal (usually http://localhost:5173).

## Build
    npm run build

## Structure
    timetable-react/
    ├── index.html
    ├── package.json
    ├── vite.config.js
    └── src/
        ├── main.jsx   (entry point)
        ├── App.jsx    (UI + scheduling engine)
        └── App.css    (styles)
